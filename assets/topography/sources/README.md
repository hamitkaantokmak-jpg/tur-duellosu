# Acquisition provenance

Acquired 2026-11-10. These are terrain samples, **not surveyed asphalt**. Original service responses and geographic query points are retained in `*-raw.json`; transformed/filter/interpolation samples are in `../profiles.json`.

- Centerlines: Tomislav Bacinger, MIT, [COTA](https://github.com/bacinger/f1-circuits/blob/master/circuits/us-2012.geojson), [Spa](https://github.com/bacinger/f1-circuits/blob/master/circuits/be-1925.geojson). Copyright and permission notice: `CENTERLINE-LICENSE.txt`. Approximate references, no survey accuracy asserted.
- COTA elevation: USGS 3DEP, [raster 116248 metadata](https://elevation.nationalmap.gov/arcgis/rest/services/3DEPElevation/ImageServer/116248?f=pjson), `TX_Central_B1_2017`, 1 m. [USGS reuse terms](https://www.usgs.gov/3d-elevation-program/about-3dep-products-services): free without use restrictions / US Government public domain. NAVD88. Query WGS84 EPSG:4326; service EPSG:3857. Query explicitly locks raster 116248 and requests bilinear interpolation; responses must confirm raster and resolution. No remote service is contacted during application playback.
- Spa elevation: © Service public de Wallonie (SPW), *Relief de la Wallonie – Modèle Numérique de Terrain (MNT) 2021–2022 (2024-01-23)*. [Dataset and CC BY 4.0 terms](https://geoportail.wallonie.be/catalogue/a004e570-99d6-4fe5-b83d-49b774409278.html), [license](https://creativecommons.org/licenses/by/4.0/). Source EPSG:3812, DNG EPSG:5710, meters, 0.5 m raster. Regional published absolute vertical accuracy ~0.12 m is not an asphalt accuracy guarantee. Identify accepts WGS84 geographic points, converts on server. Raw per-query responses remain auditable. Modifications: centerline sampling, circular smoothing, origin subtraction, periodic interpolation; no banking inferred.

Acquisition scripts are explicit offline tools. If the Node TLS route to Wallonie times out, `scripts/fetch-spa-topography.ps1` sends the same Identify requests through the Windows HTTP client. Acquisition failures must not be replaced by invented samples. Missing/invalid raw input is not a passing data validation.

`scripts/prepare-real-topography.cjs` verifies the exact centerline SHA256, applies one circular `[1,2,1]/4` smoothing pass, records filter residuals, subtracts station-zero height, and appends an explicit periodic closure. Raw points are DEM queries; none are claimed to be independent asphalt measurements. The runtime monotone cubic interpolates between filtered points; its intermediate values are derived, not new observations.
